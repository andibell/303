# BOM Pilot demo

A self-contained demonstration of a materials request workflow. It uses synthetic sample data only and has no connection to external systems.

## Run locally

```sh
npm install
npm run dev
```

## Checks

```sh
npm run check
npm run build:review
```

The review build is designed to open from `dist/index.html` without a server or network connection.

## Data and assets

The sample records are fictional. Source documents, interview transcripts, client-specific reference materials, logos, and supplied fonts are intentionally not included.
